how they're made

One job each

An agent that does one thing is easy to test, easy to trust and easy to replace. These two even keep each other honest: Forge builds Toad, Toad tests Forge.

Your machine, your keys

They run locally with your own model key. Your code, settings and results stay in your project.

Plug into what you use

Toad is an MCP server that Claude Code, Codex, Pi or Cursor can call. Pi Forge is a package for Pi. Nothing new to learn.
